## Unresolved acceptance risks

The current research validation can bind executed WFO, final holdout and
seeded circular-block MC scenarios, but external regime and feed-stress
scenarios are supplied inputs, not independently generated by the engine.
The ORB reference has a policy-bound `TEST_ONLY` options-buy backtest fixture,
but it does not establish a licensed historical option-chain backtest or
production execution economics. Options model assumptions and local batch state
remain research primitives. An Owner-approved production ORB protective policy
and evidence-derived numeric promotion profiles are absent by design; neither
is required to qualify this research-only Phase 4.
Supplied trade metrics are not independently calculated from a trusted paper
authority, so even an explicit numeric profile remains `NON_PROMOTABLE` with
`UNVERIFIED_METRICS` until that authority is implemented and tested.

G4 research-only qualification requires a successful exact-head dual-Windows
run on this document's final commit and review of the limitations above. The
implementation and previous evidence commit passed run 116; the final document
commit must also pass before acceptance. No G4 result can enable Live or promote
a strategy.
