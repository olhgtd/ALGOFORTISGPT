# Phase 9 Central Privacy Backup/Restore Runbook

Version: `RUNBOOK_CENTRAL_PRIVACY_BACKUP_RESTORE/v1`

Only registry-approved central account/consent/privacy/support classes are eligible. Broker credentials, private keys, strategies, positions, balances, raw trade logs and local trading state are rejected. Require retention/expiry plus encryption/access evidence references. Restore only to an isolated target and record audit evidence.
